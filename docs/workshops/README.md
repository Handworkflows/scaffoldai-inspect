# Workshop-Archiv

Dieser Ordner enthält die lebende, strukturierte Wissensbasis aus Produkt- und Fachworkshops. Originalquellen werden nicht verschoben oder überschrieben. Eine Workshop-Zusammenfassung verdichtet Erkenntnisse und verlinkt daraus entstandene Product Maps, Backlogs, Domänenmodelle, Workflows und Entscheidungen.

## Konvention

Jeder Workshop erhält einen eigenen Ordner:

```text
docs/workshops/
├── W-001-project-lifecycle/
│   └── SUMMARY.md
├── W-002-<thema>/
│   └── SUMMARY.md
└── W-003-<thema>/
    └── SUMMARY.md
```

Eine Zusammenfassung dokumentiert mindestens:

- Zweck, Datum/Stand und Quellenlage
- zentrale Erkenntnisse und Begriffe
- Prozess und Rollen
- Produktideen und Prioritäten
- getroffene oder vorgeschlagene Entscheidungen
- offene Fragen und Folgearbeiten
- Links auf abgeleitete Dokumente
