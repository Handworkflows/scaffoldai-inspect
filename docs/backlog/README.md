# Produkt-Backlog

In diesem Ordner werden neue Ideen gesammelt, bevor sie als konkrete Tickets geplant werden. Ein Eintrag im Backlog ist noch keine Zusage zur Umsetzung. Ideen werden regelmäßig geprüft, geschärft und priorisiert.

## Inhalt eines Eintrags

Jede Idee erhält mindestens folgende Angaben:

- **Beschreibung:** Was soll entstehen oder verbessert werden?
- **Nutzen:** Welches Problem wird gelöst und für wen?
- **Aufwand:** Erste Einschätzung der benötigten Umsetzung, zum Beispiel klein, mittel oder groß.
- **Priorität:** Bedeutung im Verhältnis zu anderen Vorhaben.
- **Status:** Aktueller Stand, zum Beispiel Idee, in Prüfung, geplant, verworfen oder umgesetzt.

## Vorlage

```markdown
# Titel der Idee

## Beschreibung

## Nutzen

## Aufwand

## Priorität

## Status
```
