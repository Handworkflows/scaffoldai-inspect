# Epics

Epics übersetzen verbindliche Workshop-Entscheidungen in geordnete Umsetzungspakete. Sie erzeugen keine neue Fachlogik, sondern definieren Scope, Abhängigkeiten, Tickets und gemeinsame Abnahmeregeln.
