# T-007.1 – Architecture Update

## Ziel

Nutze die Erkenntnisse aus den Workshops W-002 und W-003, um die Produktarchitektur zu verbessern.

WICHTIG:

Es wird keine Software entwickelt.

Es werden ausschließlich Architektur- und Dokumentationsdateien aktualisiert.

Keine bestehende Funktion verändern.

Keine UI verändern.

Keine Daten löschen.

---

## MASTER_VISION

Ergänze folgende Grundprinzipien:

- ScaffoldAI bereitet Arbeit vor, statt sie vollständig zu übernehmen.
- Entscheidungen bleiben beim Menschen.
- Material soll möglichst ohne unnötige Lageraufenthalte zwischen Baustellen fließen.
- Jede Baustelle besitzt einen messbaren Vorbereitungsgrad (Baustellen-Readiness).
- Jede Information wird nur einmal erfasst.
- ScaffoldAI reduziert ungeplante Telefonate und Rückfragen.

---
