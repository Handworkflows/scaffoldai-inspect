# Abgeschlossene Tickets

In diesem Ordner werden abgeschlossene Tickets archiviert. Ein Ticket wird hier abgelegt, sobald es umgesetzt, anhand seiner Definition of Done validiert und abgeschlossen wurde.

Die archivierten Tickets dokumentieren den ausgelieferten Umfang und machen die Entwicklung des Produkts nachvollziehbar. Nachträgliche Änderungen erhalten ein neues Ticket; der ursprüngliche Abschluss bleibt als historischer Stand erhalten.
