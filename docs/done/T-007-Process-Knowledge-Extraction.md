# T-007 – Process Knowledge Extraction

## Ziel

ScaffoldAI besitzt inzwischen umfangreiches Fachwissen aus dem ersten großen Workshop (W-001 – Lebenszyklus eines Gerüstbauprojekts).

Dieses Wissen darf nicht nur im Chat existieren.

Es soll dauerhaft strukturiert dokumentiert werden und künftig als Grundlage für sämtliche Brain-Module, Entwicklungstickets und Architekturentscheidungen dienen.

Dieses Ticket dient ausschließlich der Wissensextraktion.

Es wird **keine Software entwickelt.**

---

# Aufgaben

## 1. Product Map

Erstelle oder erweitere eine vollständige Product Map.

Ordne sämtliche Module logisch ein.

Mindestens:

- CRM & Vertrieb
- Angebotswesen
- Projekte
- Baustellenakte
- Baustellenbesuche
- Aktivitäten
- Dokumente
- Material
- Lager
- Disposition
- Mitarbeiter
- Fahrzeuge
- Brain
- Administration
- Geschäftsführung

Zeige Beziehungen zwischen den Modulen.

- Zukünftige KI-Funktionen

## 9. Wissensarchiv

Lege einen neuen Ordner an:

docs/workshops/

Verschiebe W-001 NICHT.

Erstelle stattdessen eine strukturierte Zusammenfassung des Workshops.

Der Workshop bleibt dauerhaft erweiterbar und dient künftig als lebende Wissensbasis.

Alle zukünftigen Workshops (W-002, W-003, …) sollen ebenfalls dort abgelegt werden.

---

# Regeln

- Keine Programmierung
- Keine UI ändern
- Keine bestehenden Funktionen ändern
- Keine Datenmodelle verändern
- Nur Dokumentation
- Nur Wissensextraktion
- Commit erstellen
- Push nach origin/main
