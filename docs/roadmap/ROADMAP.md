# Produkt-Roadmap

Die Roadmap beschreibt die geplante Entwicklung von ScaffoldAI. Reihenfolge und Umfang können sich durch Erkenntnisse aus der praktischen Nutzung verändern.

## MVP

Das MVP schafft den zentralen Projektkontext und die Grundlagen für eine durchgängige Baustellendokumentation.

- [x] **T-001 Dashboard** – zentrale Arbeitsoberfläche und Projektüberblick
- [x] **T-002 Projekt-Assistent** – strukturierte Anlage neuer Projekte
- [x] **T-003 Baustellenbesuche** – projektbezogene Termine anlegen und öffnen
- [ ] **T-004 Dynamische Baustellen-Workflows** – Abläufe passend zur Besuchsart bereitstellen
- [ ] **T-005 Fotos** – Bilder erfassen, zuordnen und dokumentieren
- [ ] **T-006 Notizen** – Beobachtungen und Absprachen festhalten
- [ ] **T-007 Sprache** – Informationen per Sprache erfassen
- [ ] **T-008 Brain** – kontextbezogene Assistenz im Projekt

## Version 0.2

Version 0.2 erweitert die Baustellendokumentation um kaufmännisch und technisch relevante Projektdaten.

- Material
- Nachträge
- Aufmaß

## Version 0.3

Version 0.3 verbindet Projekte mit den betrieblichen Material- und Logistikprozessen.

- Materialverwaltung
- Logistik
- Lager

## Version 1.0

Version 1.0 bildet den durchgängigen Prozess von der Kalkulation bis zur Abrechnung ab und ergänzt ihn um intelligente Unterstützung.

- Angebot
- Abrechnung
- KI-Assistent
