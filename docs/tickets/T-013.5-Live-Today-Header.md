# T-013.5 – Live Header auf "Heute"

## Ziel

Die Seite "Heute" soll lebendiger wirken.

Im Kopfbereich wird neben dem Datum eine aktuelle Uhrzeit angezeigt.

Die Uhr dient als Live-Indikator der Arbeitszentrale.

---

# Darstellung

Im Header anzeigen:

Heute

Montag, 10. August 2026                           14:37 Uhr

Die Uhr wird im 24-Stunden-Format angezeigt.

Sekunden werden nicht angezeigt.

Die Uhr aktualisiert sich automatisch mindestens einmal pro Minute.

---

# Optional

Eine tageszeitabhängige Begrüßung anzeigen.

Beispiele:

Guten Morgen

Guten Tag

Guten Abend

Diese Begrüßung soll dezent sein und den eigentlichen Arbeitsinhalt nicht verdrängen.

---

# Anforderungen

- Datum bleibt erhalten.
- Uhr läuft automatisch.
- Keine manuelle Aktualisierung erforderlich.
- Responsive Darstellung.
- Keine zusätzliche Bibliothek verwenden.
- Keine Auswirkungen auf Routing oder Datenmodell.

---

# Validierung

- Uhr aktualisiert sich automatisch.
- Datum bleibt korrekt.
- Keine Hydration-Warnungen.
- npm run lint
- npm run build

Nicht committen.

Nicht pushen.
