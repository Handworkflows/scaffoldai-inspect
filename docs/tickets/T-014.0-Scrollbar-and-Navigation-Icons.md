# T-014.0 – Scrollbar & Navigation Icons

## Ziel

Die Oberfläche soll hochwertiger und ruhiger wirken.

Dafür werden:

1. sichtbare Standard-Browser-Scrollleisten optisch vereinheitlicht
2. unnötige parallele Scrollbereiche reduziert
3. die Hauptnavigation mit klaren, kleinen Icons ergänzt

Keine Fachlogik ändern.

---

# 1. Scrollbars

Die aktuellen Standard-Scrollleisten wirken wie ein Fremdkörper im Dark Theme.

Ziel:

- schmal
- dezent
- zum Dark Theme passend
- abgerundet
- nicht dominant

Desktop-Richtwert:

- Breite ca. 6–8 px
- Track möglichst unauffällig
- Thumb dunkelgrau / anthrazit
- Hover leicht heller beziehungsweise mit bestehendem Cyan-Akzent
- keine helle Windows-Standardoptik

Firefox und Chromium-basierte Browser berücksichtigen.

---

# 2. Scrollbereiche

Mehrere sichtbare Scrollleisten gleichzeitig möglichst vermeiden.

Insbesondere prüfen:

- Hauptinhalt
- rechte Hinweisleiste
- Sidebar

Ziel:

- Sidebar bleibt fix und benötigt im normalen Desktoplayout keine sichtbare Scrollbar
- Hauptinhalt ist der primäre vertikale Scrollbereich
- rechte Hinweisleiste möglichst nicht als störender zweiter Scrollbereich darstellen

Falls ein eigener Scrollbereich fachlich notwendig ist:

- Scrollbar extrem dezent gestalten
- nur bei tatsächlichem Overflow
- keine unnötig permanente Darstellung

Keine Inhalte abschneiden.

---

# 3. Smooth Scrolling

Dezentes:

scroll-behavior: smooth

verwenden, sofern dadurch keine unerwünschten Seiteneffekte entstehen.

Keine Animationen übertreiben.

---

# 4. Navigation Icons

Die linke Hauptnavigation erhält kleine, hochwertige Icons.

Keine Buchstaben-Platzhalter wie:

H
A
P
K

mehr verwenden.

Icons sollen:

- einheitlicher Stil
- ungefähr gleiche optische Größe
- dezent im inaktiven Zustand
- Cyan/Akzentfarbe im aktiven Zustand
- gut erkennbar
- nicht verspielt

Bestehende Icon-Bibliothek verwenden, falls bereits vorhanden.

Keine neue Bibliothek installieren, wenn das bestehende Projekt bereits geeignete Icons besitzt.

---

# 5. Vorläufige Icon-Zuordnung

Für die aktuell sichtbaren Menüpunkte beziehungsweise die kommende Navigation sinnvoll zuordnen:

- Heute → Home / Dashboard / House
- Angebote → FileText / Clipboard / Briefcase
- Einsatzvorbereitung → ClipboardCheck / ListChecks
- Projekte → Folder / Building / HardHat
- Buchhaltung → Receipt / Wallet / Euro
- Arbeitsplatz → Inbox / Briefcase
- Team → Users
- Unternehmen → Building2
- Material → Package / Boxes
- Dokumente → FileText
- Brain → Brain
- Kalender → Calendar
- Einstellungen → Settings

Die konkreten Symbole anhand der vorhandenen Icon-Bibliothek auswählen.

---

# 6. Sidebar

Icons und Text sauber ausrichten.

Ziel:

[Icon] Heute
[Icon] Angebote
[Icon] Einsatzvorbereitung
[Icon] Projekte

Keine übergroßen Icons.

Keine zusätzlichen farbigen Kästen um jedes Icon.

Aktiver Menüpunkt bleibt klar erkennbar.

---

# 7. Responsive

Desktop:

- Sidebar sauber und ruhig
- keine unnötigen Scrollleisten

Mobile:

- Navigation weiterhin vollständig nutzbar
- keine Scroll-Probleme
- keine abgeschnittenen Menüpunkte

- Desktop funktioniert
- Mobile funktioniert
