# T-016.3 – Activity Template Engine

## Ziel

Die Activity Engine erhält eine generische Template Engine.

Activity-Templates definieren ausschließlich:

- Felder
- Checklisten
- Dokumentanforderungen
- Folgeactivity-Vorschläge
- Kontextinformationen

Die Engine führt selbst keine Fachentscheidungen aus.

---

# Architektur

Implementiere:

lib/activity-templates/

Mindestens:

- Template Registry
- Template Resolver
- Overlay Resolver
- Blocker Resolver

Keine Logik in React-Komponenten.

---

# Template-Aufbau

Ein Template besteht aus:

Basis

+

Activity-Typ

+

Leistungs-Overlay

+

Kontext-Overlay

+

Firmen-Overlay

=

fertiges Activity Template

- Statik erforderlich
- Nachtarbeit
- Wochenendarbeit

Mehrere Overlays gleichzeitig.

---

# Resolver

Beim Öffnen einer Activity:

Template laden

↓

Overlays anwenden

↓

Doppelte Punkte entfernen

↓

Blocker berechnen

↓

Formular erzeugen

↓

Checkliste erzeugen

↓

Kontext erzeugen

---

# Blocker

Beispiele:

Montagefreigabe blockiert wenn:

- Statik erforderlich aber fehlt

- Sondernutzung erforderlich aber fehlt

- Material fehlt

- Kolonne fehlt

Blocker verhindern Freigaben.

Nicht nur Warnungen.

---

# Dynamische Formulare

Alle Felder entstehen ausschließlich aus Templates.

Keine if(type=="Montage")-Blöcke mehr in React.

---

# Checklisten

Komplett Template-basiert.

Fortschritt automatisch berechnen.

---

# Dokumentanforderungen

- Fotos

- Unterschrift

# Folgeactivities

↓

Kontrolle

↓

Nacharbeit

↓

Abschlagsrechnung

Nur Vorschläge.

Keine automatische Erstellung.
