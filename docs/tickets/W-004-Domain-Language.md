# W-004 – ScaffoldAI Domain Language

## Ziel

ScaffoldAI soll überall dieselbe Fachsprache verwenden.

Der Workshop definiert die verbindliche Domänensprache der Anwendung.

Nicht technisch.

Sondern aus Sicht eines Gerüstbauunternehmens.

---

# Aufgabe

Prüfe sämtliche Begriffe der bestehenden Anwendung.

Bewerte sie aus Sicht:

- Bauleiter
- Vorarbeiter
- Gerüstbauer
- Disponent
- Geschäftsführer

---

# Für jeden Begriff

- Ist er fachlich richtig?
- Wird er im Alltag tatsächlich benutzt?
- Ist er verständlich?
- Sollte er ersetzt werden?
- Gibt es einen besseren Begriff?

---

Dashboard

---

# Ziel

Eine verbindliche Begriffsliste.

Für jeden Begriff festlegen:

- bevorzugter Name
- alternative Begriffe
- Definition
- Einsatzbereich
- Begründung

---

# Zusätzlich

Erkenne doppelte oder widersprüchliche Begriffe.

Schlage Vereinheitlichungen vor.

---

# Ergebnis

Erstelle das offizielle Domain Language Dictionary von ScaffoldAI.

Überarbeite vorhandene Dokumente nur, wenn dadurch Widersprüche beseitigt werden.

Keine Software ändern.

Keine UI ändern.

Nicht committen.

Nicht pushen.
