# Architekturentscheidungen

In diesem Ordner dokumentieren wir wichtige fachliche und technische Architekturentscheidungen. Die Dokumentation hält nicht nur das Ergebnis fest, sondern auch den Kontext, betrachtete Alternativen und die Konsequenzen. Dadurch bleiben Entscheidungen später nachvollziehbar und können bei veränderten Anforderungen bewusst überprüft werden.

Beispiele für relevante Entscheidungen:

- Warum bilden Baustellenbesuche den zeitlichen Projektkontext?
- Warum werden unterschiedliche Tätigkeiten als Workflows modelliert?
- Warum wird LocalStorage in der aktuellen Produktphase eingesetzt?

## Empfohlener Aufbau

Jede Entscheidung sollte einen Titel, ein Datum und einen Status enthalten sowie Kontext, Entscheidung, Alternativen und Konsequenzen beschreiben.
